# Lattice Ink 客户端

[English](README.md) · [文档导航](../../docs/README.zh-CN.md) · [开发者参考](development.zh-CN.md)

这是 Lattice 的另一种终端界面，支持多个对话标签。它连接已经运行的 Lattice 后台服务，不会替你启动服务或配置模型账号。

## 先启动后台服务，再启动客户端

需要 Node.js 和 npm，包声明的 Node.js 下限为 18。下面从源码运行后台服务的命令还需要 [Rust 构建依赖](../../docs/installation.zh-CN.md#现在可用的源码构建)。

**1. 准备模型配置。** 按[模型配置](../../docs/model-configuration.zh-CN.md)操作。配置和凭证必须在启动**后台服务**的终端里可用；在客户端终端补一个密钥，不会改变已经启动的服务。服务只检查本地配置，不验证提供方认证是否成功，也不会打开终端配置向导。

**2. 启动后台服务。** 从仓库根目录运行：

```bash
cargo run --bin lattice -- serve
```

这会把仓库作为工作目录。如果要在其他项目中工作，应从那个项目目录启动已验证的程序，并传入 `serve`。工作目录不是文件系统沙箱。

**3. 启动客户端。** 另开一个终端，从仓库根目录运行：

```bash
cd clients/ink
npm install
npm start
```

默认连接路径为 `~/.lattice/daemon.sock`。设置 `LATTICE_SOCKET` 时，两边必须使用相同路径。`LATTICE_STREAM` 选择客户端连接的对话名，默认为 `main`。两个客户端连接同一名称时，共享同一段对话，不是各自的副本。

连接失败时，先确认后台服务启动成功、连接路径一致，再重开客户端；客户端不会自动重连。不要把删除已有 socket 当成常规修复，另一个服务可能正在使用它。账号或启动错误见[故障排查](../../docs/troubleshooting.zh-CN.md)。

## 日常操作

| 操作 | 实际作用 |
| --- | --- |
| `Enter` | 发送草稿。 |
| `Tab` | 切换标签。 |
| `Esc` | 请求中断当前忙碌的对话。影响的是共享对话，不是回滚。 |
| `/new [name]` | 在标签中打开或连接对话。省略名称时由客户端生成；复用已有名称可能回到旧工作，不是重置。 |
| `/btw [question]` | 打开独立侧会话，可只读查看父会话历史而不打断它；侧会话自己的工具不会因此变成只读。 |
| `/tab <n>` | 切换到指定编号的标签。 |
| `/close` | 关闭本客户端当前标签及订阅，但最后一个标签不会关闭。后台对话仍保留。 |
| `/exit` 或 `Ctrl-C` | 退出客户端，不停止后台服务，也不会因此中断服务中正在进行的工作。 |
| `/clear` | 只清当前标签的实时显示记录。不重置模型上下文、不删除历史、不取消工作、不撤销授权；正在查看的旧页仍保留。 |

只有明确支持的本地命令会被截获。其他斜杠开头的文字会当成对话文本发送，不要把 `/reset` 当成已经实现的重置功能。

## 查看更早的历史

用 `/older` 每次读一页更早的记录，用 `/latest` 重新连接到最新位置。`/latest` 不是网络重连命令，而且会结束旧绑定的临时权限。

界面最多保留 500 条实时显示记录和当前旧页，不会自动下载全部历史。这是显示上限，不是模型上下文上限，也不是删除历史的规则。查看旧页不会恢复旧的忙碌或授权状态，实时更新仍会到达。读取失败时位置保留，可以再尝试。

## 授权前看清范围

后台服务兼容且具有相应服务时，授权卡提供以下快捷键，**只在草稿为空时生效**：

- `y`：仅批准本次；`n`：拒绝。
- `f`：保存当前卡实际提供的流内授权范围；不是每张卡都有这项选择。
- `p`：在卡片提供时，明确授予引入项永久信任。这与流内授权不同。

看清显示的范围。命令前缀授权可以允许追加参数，但不绑定工作目录、远端映射或可执行文件内容，也不是文件系统沙箱。批准 `git push origin`，不代表每次推送的目的地都会重新独立核验。

`/permission [on|off]` 查看或修改当前界面的临时权限，`Shift+Tab` 切换它且不提交、不清空草稿。`/grants` 列出流内授权，`/revoke <id>` 请求撤销列出的授权，不撤销永久信任或已经完成的操作。界面等待服务端确认，不会先宣称成功。打开开关不会自动回答当前待答卡。

关闭绑定、断线、执行 `/latest` 重新绑定，或重开运行时，都会结束临时权限。流内授权另行保留，永久信任又是另一套机制。旧版后台服务或缺少相应服务时，新控件不可用；旧版 `y` 保留旧服务语义，可能授予永久信任，不能理解成“仅本次”。

## 数据与求助

对话和工具输出可能含秘密，并会发送给配置的模型提供方。中断、关闭标签、退出客户端，都不会撤销已经发生的操作。处理敏感工作前先读[数据与权限边界](../../docs/getting-started.zh-CN.md#数据与权限)。求助时说明出问题的功能或步骤，提供检查过的一小段诊断，不上传全部历史或环境变量，见[支持渠道](../../SUPPORT.md)。

协议消息、后端边界、源码布局和测试命令在[开发者参考](development.zh-CN.md)中，不是使用客户端的前提。
