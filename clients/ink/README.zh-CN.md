# Lattice Ink 客户端

[English](README.md) · [文档导航](../../docs/README.zh-CN.md) · [开发者参考](development.zh-CN.md)

Ink 是 Lattice 的另一种终端界面，可以用多个标签同时查看不同对话。使用时先配置模型并启动 Lattice 后台服务，再打开客户端连接它。

## 先启动后台服务，再启动客户端

准备 Node.js 18 或更新版本以及 npm。从源码启动后台服务，还需要 [Rust 构建依赖](../../docs/installation.zh-CN.md#现在可用的源码构建)。

**1. 准备模型配置。** 按[模型配置](../../docs/model-configuration.zh-CN.md)设置账号。请在启动**后台服务**的终端里准备好配置和密钥，服务会在启动时读取它们。后台服务直接使用这些配置，首次配置请先通过普通终端引导或编辑配置文件完成。

**2. 启动后台服务。** 从仓库根目录运行：

```bash
cargo run --bin lattice -- serve
```

这会把仓库作为工作目录。要处理其他项目时，从那个项目目录运行已经构建好的 `lattice serve`。工具也能访问工作目录以外的文件。

**3. 启动客户端。** 另开一个终端，从仓库根目录运行：

```bash
cd clients/ink
npm install
npm start
```

默认连接路径是 `~/.lattice/daemon.sock`。通过 `LATTICE_SOCKET` 更换路径时，让两边使用同一个值。`LATTICE_STREAM` 指定对话名称，默认是 `main`。两个客户端使用同一名称，就会一起操作同一段对话。

连接失败时，先确认后台服务正在运行、两边路径相同，再重开客户端连接。保留已有连接文件，其他服务可能正在使用它。账号或启动错误见[故障排查](../../docs/troubleshooting.zh-CN.md)。

## 日常操作

| 操作 | 作用 |
| --- | --- |
| `Enter` | 发送输入框里的内容。 |
| `Tab` | 切换标签。 |
| `Esc` | 请求中断当前正在工作的对话；连接同一对话的其他客户端也会看到变化。 |
| `/new [name]` | 打开指定名称的对话标签。省略名称会自动生成新名称；填写已有名称会连接那段对话。 |
| `/btw [question]` | 打开一个能读取当前对话历史的侧会话，讨论另一件事。当前对话继续运行，侧会话中的工具也能执行操作。 |
| `/tab <n>` | 切换到第 n 个标签。 |
| `/close` | 关闭当前标签，保留后台对话；最后一个标签保持打开。 |
| `/exit` 或 `Ctrl-C` | 退出客户端。后台服务及其中的任务继续运行。 |
| `/clear` | 清空当前标签的实时显示。模型上下文、保存的历史、正在运行的任务、授权和正在查看的旧页都保留。 |

其他斜杠开头的文字会作为消息发送给模型，例如 `/reset`。执行客户端操作时，使用上面列出的命令。

## 查看更早的历史

用 `/older` 向前翻一页，用 `/latest` 回到最新位置。`/latest` 会重新连接当前对话，同时结束当前标签此前的临时权限；网络连接断开时，需要重新启动客户端连接。

界面显示最近最多 500 条实时记录，以及你正在查看的一页旧记录。完整历史继续保存在后台，模型上下文另外管理。查看旧页时仍会收到新消息，权限和工作状态以当前服务状态为准。翻页失败时位置保留，可以再试一次。

## 授权前看清范围

需要授权时，后台服务会发来卡片。输入框为空时，可以使用以下快捷键：

- `y`：批准本次请求；`n`：拒绝。
- `f`：保存卡片显示的当前对话授权范围，卡片提供这个选项时可用。
- `p`：永久信任卡片所列的请求，卡片提供这个选项时可用。

命令前缀授权会允许后面追加参数。例如允许 `git push origin` 后，它会使用执行时的工作目录和 `origin` 配置；目录、远端地址或程序内容改变后，原授权仍可能适用。需要逐次确认时，选择仅批准本次。

| 命令或按键 | 作用 |
| --- | --- |
| `/permission [on\|off]` | 查看或切换当前标签连接这段对话时的临时操作权限。 |
| `Shift+Tab` | 切换临时操作权限，保留输入框中的内容。 |
| `/grants` | 查看当前对话的授权。 |
| `/revoke <id>` | 请求撤销列表中的一项授权，等待后台服务确认。 |

打开临时权限后，已经显示的待答卡片仍需单独回答。关闭当前标签、断线、使用 `/latest` 重新连接当前对话，或重启后台服务，都会结束这份临时权限。当前对话的授权另外保存，永久信任则另外管理；撤销授权后，已完成的操作仍会保留。

这些快捷键需要配套的后台服务。连接旧版服务时，部分控件不可用，旧版 `y` 还可能授予永久信任。先核对卡片显示的范围，再批准请求。

## 数据与求助

对话和工具输出会保存，并发送给配置的模型服务，其中可能含有文件内容和密钥。取消任务、关闭标签或退出客户端后，已经发生的操作仍会保留。更多说明见[数据与权限](../../docs/getting-started.zh-CN.md#数据与权限)。

求助时说明出问题的功能或步骤，提供去掉密钥和私密内容的错误片段，见[支持渠道](../../SUPPORT.md)。协议、源码布局和测试方法见[开发者参考](development.zh-CN.md)。
