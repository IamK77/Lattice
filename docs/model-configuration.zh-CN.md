# 模型配置

[文档导航](README.zh-CN.md) · [第一次对话](getting-started.zh-CN.md) · [English](model-configuration.md)

这里介绍怎样连接模型服务、填写容量和保存设置。第一次使用可以先跟着[分步引导](getting-started.zh-CN.md#2-连接模型)操作，需要了解某个选项时再来查。

## 选择连接方式

下面先介绍首次启动时的配置引导。已有可用模型时，启动会直接进入对话；要修改已保存的地址或容量，按[手动配置](#手动配置)找到并编辑模型文件。

选择 OpenAI、Anthropic 或 DeepSeek 后，引导会填入建议的接口格式和服务地址。其他服务选择自定义配置；已有配置也可以在这里修复。填写密钥前，确认地址属于你要连接的服务。

模型名称可以从服务返回的列表中选择，也可以手动填写。获取列表失败时，继续手动配置即可。已经获取的名称可以搜索，也支持 Tab 补全；补全直接使用已有列表。名称太长时，可以在列表中搜索选择。

保存前，检查服务地址、模型名称、接口格式，以及是否将它设为默认模型。其他选项在**更多设置与详情**中，包括配置保存位置、能力资料的来源、本地名称和语言。选择保持原默认模型时，之前的选择会保留。

**连接测试**会发送一个简短问题，检查服务能否回答。测试按服务的计费规则收费，也可以跳过。失败后，引导会提供重试、修改、跳过和退出选项，由你决定下一步。图片输入等能力按服务说明选择。思考档位用来记录模型支持哪些强度，实际使用的强度在对话中选择。

## 能力与容量

### 填写容量

容量决定一次对话请求能容纳多少内容，单位是 token（模型计算内容长度的单位）。主要填写两个数：

- **上下文容量：** 一次请求中，输入内容与模型回复合计的上限。
- **最大输出量：** 一次回复的长度上限。这个数应小于上下文容量，为你的问题和已有对话留出空间。

引导会使用已有的型号资料，缺少数值时再询问。按你所用服务的说明填写即可。可以输入整数，也可以用 `k` 或 `M` 简写：`32k` 表示 `32000`，`1.5M` 表示 `1500000`，大小写均可。服务给出 `1048576` 这样的精确数值时，直接照填。确认时会显示展开后的数值；输入有误时，页面会提示修改。

服务有时只提供输入上限。对于 Anthropic，引导会把这个数作为总容量的保守建议，不额外加上输出量。请对照服务说明确认或修改。

### 选择能力

在能力列表中按空格勾选，按回车确认。不确定是否支持图片输入、服务端搜索或图片生成时，可以先不启用这些功能。

- **图片输入**是让模型看图，**图片生成**是让服务画图。服务端搜索和图片生成使用 Responses 接口格式。
- **思考档位**列出模型支持哪些思考强度；这里配置可选项，实际使用时再选择强度。常见档位按由弱到强排列，自定义档位保留原顺序。

## 语言、返回与保存

### 切换语言

配置首页可直接选择 **Language / 语言**。已经进入新模型的检查页面时，在**更多设置与详情**中切换。修复密钥时，这个选项放在总览页。它用于配置引导和密钥修复页面。

选择会保存到偏好的 `setupLanguage` 字段，值为 `en` 或 `zh-CN`。初次使用时，引导依次查看 `LC_ALL`、`LC_MESSAGES`、`LANG`，中文环境显示简体中文，其余显示英文；主动选择语言后，以保存的选择为准。偏好保存失败时，当前引导仍使用你选的语言，并显示保存错误。服务返回的诊断保留原文，方便查找原因。

### 返回或退出

Esc 返回上一步，在首页按 Esc 退出。等待输入时也可以按 Ctrl-C 退出。网络请求期间按取消，会等当前请求结束后处理，程序不会因此再发一次请求。

已经确认的字段会保留在本次引导的草稿里，返回首页后也可以继续填写。输入框中尚未确认的文字，在取消时会丢弃。保存模型前退出，草稿不会写成模型配置；退出前已经保存的语言选择会保留。

### 修改连接信息

更换地址、接口格式或账号后，需要重新获取列表并确认能力；更换模型后也要重新确认能力。更换地址时重新填写密钥，旧密钥不会自动带到新地址。重新获取同一模型的资料时，会保留你手动修改过的字段。

### 保存遇到问题

配置文件无法读取时，先备份原文件，再按错误提示修复。Lattice 会保留原文件，避免覆盖已有账号。模型已保存、默认选择保存失败时，引导会说明情况，你仍可使用这个模型完成本次对话。下次启动时选到了其他模型，可以按[模型故障排查](troubleshooting.zh-CN.md#没有可用模型或连到了意外的提供方)检查环境变量和默认设置。

可用配置已经存在时，启动会直接进入对话；后台或非交互命令也会跳过引导。使用继续对话命令时，完成引导后仍会回到原先选择的对话。保存模型之前退出引导，会一并结束这次启动。

## 手动配置

模型配置默认保存在 `~/.lattice/models.json`。需要时先创建父目录：

```bash
mkdir -p "$HOME/.lattice"
```

用编辑器打开或创建 `models.json`。已有配置时，在原内容上添加模型。`LATTICE_MODELS` 可以指定另一个配置文件。下面用占位地址和型号展示写法，请把地址、型号和容量换成所用服务提供的值：

```json
{
  "models": {
    "my-model": {
      "adapter": "openai",
      "model": "your-model-id",
      "baseUrl": "https://api.example.invalid/v1",
      "apiKeyEnv": "LATTICE_MODEL_KEY",
      "profile": {
        "contextWindow": 32768,
        "maxOutputTokens": 4096
      }
    }
  }
}
```

`adapter` 决定接口格式。按服务说明选择对应的一行：

| `adapter` 的值 | 接口格式 |
| --- | --- |
| `openai` | Chat Completions |
| `responses` | Responses |
| `anthropic` | Anthropic Messages |

其他字段见[模型配置字段](../schemas/model_catalog.json)与[型号资料字段](../schemas/model_profile.json)。

接着提供密钥。可以使用已有的凭证管理工具，也可以在 **Bash** 中输入下面的命令，再输入密钥；输入内容会隐藏，并且不会写进 shell 命令历史：

```bash
printf 'API key: '
read -r -s LATTICE_MODEL_KEY
printf '\n'
export LATTICE_MODEL_KEY
```

保持这个终端打开，按[第一次对话](getting-started.zh-CN.md#2-连接模型)启动 Lattice。

## 密钥保存与终端操作

### 保存密钥

`apiKeyEnv` 在配置中记录环境变量名；`apiKey` 则直接记录密钥。优先使用环境变量，可以减少文件中的密钥副本。

工具能够读取这两种位置。文件或命令输出中的密钥被工具读出后，会随结果保存在对话记录中，并可能发送给模型服务。提交配置或分享记录前，请检查密钥和其他敏感内容。

Unix 系统上，引导写入密钥时使用仅文件所有者可读写的权限；运行中的 agent 也能读取该文件。无法设置这种权限的平台使用环境变量方式。引导会保留你的 shell 启动文件。

### 使用终端

请在交互式终端中运行引导，窗口至少为 40 列、14 行。每一步会更新当前页面，长说明会单独分页。调整窗口大小后，切换到下一页时会重新排版。

正常退出时会恢复原来的终端画面。强制结束进程或崩溃后，如果显示异常，可以重新打开终端。

想了解引导的实现和测试，见[配置引导开发说明（英文）](setup-development.md)。
