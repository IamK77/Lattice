# 模型配置

[文档导航](README.zh-CN.md) · [第一次对话](getting-started.zh-CN.md) · [English](model-configuration.md)

面向需要连接服务或调整设置的使用者。不需要详细配置时，直接走[分步引导](getting-started.zh-CN.md#2-连接模型)。接入模型不需要修改部件或运行时装配。

## 选择连接方式

引导提供 OpenAI、Anthropic、DeepSeek 预设、自定义配置，以及已有条目的修复。预设会建议接口格式和地址；填写凭证前请核对，两者不保证每个型号的每项能力都可用。

可以明确获取服务的模型列表、筛选名称，也可以直接手填准确型号。获取失败或列表为空不挡住手填。已获取的名称支持 Tab 补全，不额外请求；过长名称即使不适合行内补全，仍可在列表中搜索。获取列表不生成回答，也不是兼容性测试。

保存前检查模型、接口格式、地址、本地名称、默认偏好动作和主要能力。**更多设置与详情**提供完整配置、保存位置、能力来源，以及名称、默认项和语言设置。选择不修改默认偏好，不会取消此前选择的默认模型。

可选连接测试会发送一次简短请求，**可能收费**，可以跳过。失败后由你选择重试、修改、跳过或退出，不会自动重试。成功不代表工具、思考历史或每项服务端能力都已兼容。

## 能力与容量

引导使用已有资料，只追问缺失或无效的容量。请结合实际服务确认建议：

- 图片输入与服务端图片生成分开。服务端搜索和图片生成仅在 Responses 格式下提供；未知能力不勾选。
- 空格切换能力选项，回车确认。思考档位复选框声明支持哪些档位，不改变当前思考强度。常见名称按由弱到强排列，自定义名称保留原顺序。高级设置保留自定义档位名称、顺序和用量字段映射。
- 容量接受精确整数、不区分大小写的十进制缩写：`1M = 1000k = 1000000`，`1.5M = 1500000`。不是二进制单位；服务明确给出 `1048576` 时请填写这个精确值。不接受小数个 token 或溢出，也不四舍五入。提交后显示展开的数值；输出必须给输入留出空间。
- 服务报告的输入上限不一定是总上下文容量。Anthropic 输入上限会被标为**保守的总预算建议**，不会加上输出长度；请确认或修改。

## 语言、返回与保存

配置引导和密钥修复支持中英文，不改变终端主界面的语言。首页或新模型总览的**更多设置与详情**中可以选择 **Language / 语言**；密钥修复在总览直接提供此项。

明确选择的语言以 `setupLanguage`（`en` 或 `zh-CN`）保存在偏好中。没有已保存的选择时，依次参考 `LC_ALL`、`LC_MESSAGES`、`LANG`：中文环境使用简体中文，其余使用英文。自动判断不保存选择。偏好写入失败会报出，本次仍使用选定语言。提供方诊断标为原文。

Esc 返回上一步，在首页退出。等待输入时 Ctrl-C 退出；网络请求期间，取消在这次有界请求结束后处理，不因此重发请求。已提交字段留在草稿中，在输入框内取消的未提交文字不保存。回到首页保留新模型和密钥修复草稿。修改地址、接口格式或账号会使依赖的列表和能力失效；换模型会重置其能力。新地址不继承旧密钥。重新获取同一模型的资料，不覆盖已经手动修改的字段。

保存模型前取消，不创建模型条目或对话；明确保存的语言与此前保存的配置仍保留。已有可用配置会跳过引导，后台或非交互命令不会打开它。原本要求继续的对话，也不会被引导换成另一条。

不要为了跳过错误而删除损坏的模型文件：读坏的目录不会被重置。修复提示的文件后重新检查。模型保存成功、默认偏好写入失败时，引导会说明，并允许本次使用这个模型继续。下次启动时，原有环境覆盖仍可能优先，见[模型故障排查](troubleshooting.zh-CN.md#没有可用模型或连到了意外的提供方)。

## 手动配置

默认模型目录文件是 `~/.lattice/models.json`。必要时创建父目录：

```bash
mkdir -p "$HOME/.lattice"
```

用编辑器创建或编辑 `models.json`，**保留已有条目**。`LATTICE_MODELS` 可以指定其他目录文件。下面是配置形状示例，不是可用账号；端点、型号与容量请按提供方文档替换。`.invalid` 地址特意不能连接真实服务。

```json
{
  "models": {
    "my-model": {
      "adapter": "openai",
      "model": "your-model-id",
      "baseUrl": "https://api.example.invalid/v1",
      "apiKeyEnv": "LATTICE_MODEL_KEY",
      "profile": {
        "contextWindow": 32768,
        "maxOutputTokens": 4096
      }
    }
  }
}
```

| 适配件 | 端点协议 |
| --- | --- |
| `openai` | Chat Completions |
| `responses` | Responses |
| `anthropic` | Anthropic Messages |

这里选择的是协议，不是承诺支持所有提供方扩展。端点根地址、准确型号、容量和设置须适合实际服务。完整字段参考：[模型目录](../schemas/model_catalog.json)与[型号档案](../schemas/model_profile.json)。

使用已有凭证管理方式提供密钥，或在 **Bash** 中交互输入，避免把密钥值写入 shell 历史：

```bash
printf 'API key: '
read -r -s LATTICE_MODEL_KEY
printf '\n'
export LATTICE_MODEL_KEY
```

启动 Lattice 时保持这个终端打开。`apiKeyEnv` 保存的是变量名，不是密钥值；另一种写法 `apiKey` 则把密钥值存进目录文件。优先引用环境变量，不要提交真实密钥。准备好后回到[第一次对话](getting-started.zh-CN.md#2-连接模型)启动程序。

## 凭证与终端限制

- 本机保存的密钥位于 **agent 可读的文件**中；工具读取后，可能进入持久历史和模型输入。避免写入 shell 历史、改用环境变量，都不能阻止工具读取密钥。
- Unix 下，引导在写入密钥之前以仅所有者可读写的权限创建临时文件，但这不隔离 agent。不支持受保护存储的平台，不会提供被伪称为安全的本机密钥选项。引导不修改 shell 启动文件。
- 引导要求输入、输出和错误流连接交互终端，窗口至少 40 列、14 行。每个页面替换上一个任务，不累积问答；普通取消、报错和进入主界面时恢复原终端画面。强制终止或进程崩溃不在这项保证内。
- 等待输入时缩放窗口，不会立即重排整页；切换问题和详情时重新计算布局。长说明单独分页，重试只替换错误，不追加问答记录。

实现、请求记录和免模型开发检查见[配置引导开发说明（英文）](setup-development.md)，它们不是额外的配置步骤。
