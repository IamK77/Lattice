# 桌面操作

[English](desktop.md) · [文档导航](../README.zh-CN.md) · [开发者参考](../development/desktop-development.zh-CN.md)

`Desktop` 让 Lattice 查看并操作你电脑上的应用窗口，例如点击按钮、填写内容和滚动页面。使用前，需要在 macOS 上安装驱动、授予系统权限，并选择支持图片输入的模型，见[模型配置](model-configuration.zh-CN.md)。普通文字对话可以先照常使用。

## 安装与系统许可

本文按 **Cua Driver 0.26.1** 说明配置。驱动需要单独安装，Lattice 会在使用桌面工具时启动它。请从驱动发布方获取程序，并在运行前核对版本、文件摘要、归档路径和应用签名。更换驱动版本后，先用小任务检查观察和输入是否正常。

默认驱动入口是 `~/.lattice/drivers/desktop`，可以指向安装好的 `CuaDriver.app/Contents/MacOS/cua-driver`。已有入口时先查看它指向哪里。也可以在**启动 Lattice 前**，在同一个终端指定驱动位置：

```bash
export LATTICE_DESKTOP_DRIVER="/path/to/CuaDriver.app/Contents/MacOS/cua-driver"
```

自行配置装配时，`executable` 的设置优先于这个环境变量。

在**系统设置 → 隐私与安全性**里，给启动 Lattice 的终端或宿主应用开启：

- **屏幕录制**，部分系统显示为“屏幕与系统音频录制”，用于查看窗口。
- **辅助功能**，用于点击和输入。

缺少权限时，工具会提示需要开启哪一项。macOS 要求重开应用时，先结束当前会话，再由你重开终端，以免切断正在进行的对话。

## 使用方式

告诉 Lattice 要操作哪个应用、完成什么事。例如：

> 查看这个应用的设置窗口，告诉我有哪些选项。这一步先查看，等我确认后再修改。

操作按下面的顺序进行：

1. 列出窗口，选定目标应用和窗口。
2. 查看这个窗口的截图，确认当前画面。
3. 做一小批操作，再检查截图和应用中的结果。

工具支持点击、输入、按键、滚动和拖动，每批最多八项。输入时会把目标窗口带到前台；你需要继续自己的工作时，可以手动切回原窗口。窗口大小变化后重新查看截图。窗口身份变化后重新选择目标，单纯改标题可以继续使用。

截图会保存到对话记录旁，并发送给当前模型。查看前收起画面中的密钥和私密内容。桌面操作使用你本机的真实应用，应用照常读写数据和联网；桌面工具沿用现有授权流程，不会为每次点击另弹批准框。发送消息、填写凭证或删除数据前，应由你明确确认任务和范围。

## 保护与边界

### 操作中断时

一批操作可能只完成了一部分；输入后的截图失败时，输入也可能已经发生。先查看应用里的实际结果，再决定接下来做什么。

输入状态不明确时，驱动会暂停接收新的输入。此时让 Lattice 关闭驱动连接，重新列出窗口并查看截图，确认状态后再继续。已经完成的修改和对外发送仍会保留。

### 关闭连接与恢复对话

`close` 释放驱动连接和窗口记录，应用继续保持打开，已输入的内容也会保留。再次打开保存的对话时，Lattice 会读取历史，不会重新执行历史中的桌面操作。继续操作前，先查看当前窗口。

### 受保护的窗口

当前 Lattice 进程及启动它的宿主受到保护。默认配置还排除了指定的终端、代理和系统控制应用，避免操作切断当前对话。目标被拒绝时，先检查原因和配置。更换宿主或代理后，也需要检查这份排除清单。
