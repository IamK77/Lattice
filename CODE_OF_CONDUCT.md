# Community code of conduct

We want people to be able to ask questions, contribute, and disagree without
being harassed. This applies to repository issues, pull requests, discussions,
and other project-managed spaces.

## Expected behavior

- Be respectful of people with different backgrounds, experience, and abilities.
- Critique ideas and code rather than attacking the person proposing them.
- Accept corrections, explain technical disagreements with evidence, and stay
  focused on the problem being discussed.
- Respect privacy. Do not publish someone's personal information, credentials,
  or private correspondence without permission.

Harassment, threats, discriminatory abuse, sexual harassment, deliberate
intimidation, and persistent disruption are not acceptable.

## Moderation and reporting

@IamK77 maintains the project and handles moderation. Depending on severity and
context, moderation may include clarification, a warning, hiding or removing
content, locking a discussion, or restricting participation. Decisions should
explain the behavior at issue without exposing private reports.

For a non-sensitive moderation request, contact @IamK77 in the relevant project
thread. Do not post private details or amplify abusive content to report it.
For platform abuse or a report that should not be public, use
[GitHub's Report abuse process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
That report goes to GitHub, not to a separate Lattice moderation team. It is also
the available escalation path for concerns about the sole maintainer.

Lattice does not currently operate a private conduct-reporting mailbox or an
independent appeals committee. Do not use security advisories for non-security
conduct complaints. Security vulnerabilities use [SECURITY.md](SECURITY.md).
